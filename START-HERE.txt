MARKPAD 0.1.3 - PROJECT AND RELEASES

Development project: C:\repos\markpad
Extract project/update packages into that folder, NOT directly into bin.
The development application runs from bin\Markpad.exe. Keep its Electron
support files beside it. A root shortcut may point to that executable.

RELEASE DOWNLOADS
The project/publishing kit includes these complete runtime packages:
  dist\releases\Markpad-0.1.3-Setup-x64.exe
  dist\releases\Markpad-0.1.3-Portable-x64.zip
The standalone source ZIP does not include runtime binaries.

Setup installs separately under your local application folder, then offers
optional PATH/Run registration and Windows .md default-app selection.
Portable keeps settings and recoverable drafts in data beside its EXE.
Neither release automatically imports drafts from a different installation.

PUBLISH TO GITHUB
Run Publish-Markpad.cmd from this folder. Git and GitHub CLI are required.
The script uses your own GitHub login, requires account kingjoyeuse, creates
kingjoyeuse/markpad privately by default, pushes source, and uploads the
v0.1.3 prerelease. Public publishing is an explicit command-line choice:
  Publish-Markpad.cmd -Visibility public
It does not force-push or overwrite an existing release.
The repository has NOT been created or uploaded by the chat session.

See README.md and docs\RELEASING.md for build and publishing instructions.
AGENTS.md contains Codex development guidance. Windows native execution,
installer UI, PATH, default-app confirmation, and uninstall remain unverified.
The EXE downloads are unsigned. Source license remains UNLICENSED.
