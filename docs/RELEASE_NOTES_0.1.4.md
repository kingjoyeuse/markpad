# Markpad 0.1.4

- Arrow keys save an in-progress worksheet value and move to the next cell.
- While writing a formula, arrows highlight and insert cell references. Tab
  commits at the original cell, and Enter commits and moves one row below it.
- Ctrl+N preserves the current draft and opens a blank Markpad in the same
  window. Ctrl+Shift+N opens a separate window.
- Calculator and Spreadsheet each use a single Show/Hide menu item.
- Formatted mode previews supported HTML and preserves editable HTML source.
- The toolbar supports editing and breaking links, inserting HTML, and
  starting blank inline code. The table icon has a white header row.
- Fenced code blocks have a filterable language dropdown and a copy button.
